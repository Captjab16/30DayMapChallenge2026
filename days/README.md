# Days

One folder per challenge day for project files (`.aprx`, `.qgz`, `.svg`, `.ai`) and exports. Each folder's README says which files in [`data/`](../data/) that day uses.

Large or generated files (geodatabases, rasters, `.gpkg`) are gitignored here too, so keep source data in `data/`.
